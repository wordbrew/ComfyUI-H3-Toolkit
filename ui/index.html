Drag the ⋮ on a segment's right edge to change that chunk's length. Drag a segment itself to reorder. Click the round button between two segments for the transition. The inspector's Length dropdown does the same thing if you prefer typing.

    The take

    Subject, wardrobe, set, lighting, camera. Every chunk is generated with no memory of the one before, so anything not restated here is re-invented — wardrobe especially, which nothing but the words holds.

    Give the camera some drift. A truly locked-off shot is the one framing measured to degrade over a long take.

    Sound

    An instrument someone in the scene is playing is diegetic and belongs in the beat, not here — put it here and the model lays an unrelated backing track underneath.

    Both fields are empty, which asks the model for SILENCE. H3 generates audio in the same pass as the picture, so with nothing described here the take comes back quiet. Describe the room: close tone, what is audible through the wall, breath near the microphone.

    Chunk

    One continuous moment. “And then…” reads as a cut instruction — if two things happen in sequence, that is two scenes.

    What each transition does

    Repeated byte-identically into every scene of this shot. Varying it within a shot dragged wardrobe and set description along with whatever was being changed, so only a scene that starts a shot can set it — the others inherit.

    applied to this chunk alone — the schedule is built for you

    Library

    Saved subjects, reusable across takes. A subject is a person, a place or a thing — and the kind decides how the prompt asks for it to be kept: a person keeps identity and build, a place keeps layout and light, a thing keeps shape, material and markings.
